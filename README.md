# Clue-Less Game

A simplified version of the classic board game Clue, implemented as a web-based multiplayer game.

## Course Information
- **Course**: EN.605.601.85.SP25 Foundations of Software
- **Institution**: Johns Hopkins University

## Project Description
Clue-Less is a simplified version of the classic board game Clue. The game allows multiple players to connect and engage in turn-based mystery gameplay through both text-based and graphical interfaces.

## Features
- Multiplayer lobby system
- Character selection
- Game board with rooms, hallways, and secret passages
- Card distribution system
- Turn-based gameplay with move, suggest, and accuse actions
- Real-time game state updates

## Tech Stack
- **Backend**: Python, Flask, Flask-SocketIO, SQLAlchemy
- **Frontend**: HTML, CSS, JavaScript
- **Database**: SQLite
